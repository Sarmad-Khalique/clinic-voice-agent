# dashboard/  (V1)

Next.js / React dashboard: calls, transcripts, per-turn latency, eval scores. Simple password protection. Reads data through the API, not the database directly.

Stack: Next.js (App Router), TypeScript, Tailwind CSS, ESLint. Package manager: pnpm.

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm lint
pnpm build
```
